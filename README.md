# NEXOAULA

## Descripción

**NexoAula** es una plataforma web diseñada para organizar y centralizar recursos educativos disponibles en internet, proporcionando un entorno digital accesible e intuitivo para alumnos de primero a sexto grado de educación primaria.

El proyecto considera las necesidades de usuarios en etapas tempranas de alfabetización digital, quienes pueden presentar distintos niveles de familiaridad con la tecnología y habilidades psicomotrices aún en desarrollo. Por ello, prioriza una interfaz sencilla, una navegación estructurada y elementos visuales que faciliten la interacción con los recursos educativos, reduciendo las barreras de acceso y favoreciendo su aprovechamiento.

Su propósito es facilitar el acceso a contenidos educativos desde un punto centralizado, ofreciendo una experiencia de navegación consistente para alumnos y docentes, independientemente de las diferencias entre navegadores o motores de búsqueda.

El proyecto busca facilitar el trabajo docente, permitiendo que tanto el maestro como los alumnos accedan rápidamente y al unísono a los recursos en línea, sin depender de búsquedas manuales o enlaces dispersos.  
De esta forma, se aprovecha eal maximo el tiempo de navegación y se garantiza un acceso simultáneo al material educativo.

## Estado del proyecto

Esta publicación corresponde a una versión preliminar de NexoAula, destinada exclusivamente a fines demostrativos y de presentación del proyecto. No cuenta con soporte técnico público ni garantías de funcionamiento. El soporte y mantenimiento de la versión principal se gestionan de manera privada, mientras que su desarrollo continúa activo y algunas funcionalidades pueden estar sujetas a cambios.

## Tecnologías utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla)  

No requiere instalación de librerías, frameworks o dependencias externas.  
Requiere de un servidor web para su correcta visualizacion.

## Objetivo general

Reducir las barreras de acceso a los recursos educativos digitales dentro del aula multimedia mediante una plataforma centralizada que permita a docentes y estudiantes consultar y utilizar los mismos contenidos desde un punto de acceso común, evitando la dependencia de búsquedas individuales, diferencias entre motores de búsqueda o configuraciones adicionales que dificulten su localización y aprovechamiento.

## Características principales

- Interfaz accesible y adaptada para niños.  
- Organización por grados escolares.  
- Transiciones suaves entre páginas (SPA-like).  
- Copia de datos al portapapeles accesible dentro del sitio web.
- Modo de uso intuitivo tanto para alumnos como para docentes.  
- Puede escalarse fácilmente para añadir más grados, grupos o contenido.

## Implementación

NexoAula fue concebido originalmente para funcionar en un entorno de red local, por lo que su implementación actual está orientada a cubrir las necesidades operativas de dicho escenario. En consecuencia, esta versión no incorpora los mecanismos de seguridad, control de acceso y protección de datos que serían necesarios para un despliegue público en internet.

No obstante, su estructura permite contemplar una futura evolución hacia un entorno en línea, mediante la incorporación de componentes como:

- **Autenticación:** identificación y gestión de usuarios.
- **Base de datos:** almacenamiento persistente y centralizado de la información.
- **Panel de administración:** gestión de usuarios, recursos educativos y configuración de la plataforma.
